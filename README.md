## 🚀 Featured Project

### 🤝 Mentor Application

> **A complete mentoring platform built with ASP.NET Core MVC and a connected Windows desktop application.**

The project consists of two connected applications designed to manage the complete mentoring and appointment-booking workflow.

**Web Platform**

- 🔐 ASP.NET Core Identity authentication
- 🔑 Google & Facebook OAuth
- 👤 User and mentor profiles
- 🧑‍🏫 Mentor skills and availability
- 🔎 Mentor search and filtering
- 📅 Appointment scheduling
- 🚫 Double-booking prevention
- 📧 SMTP email notifications
- 🗄️ Entity Framework Core + SQL Server

**Windows Application**

- 👥 Mentor management
- 📅 Availability management
- ✅ Appointment confirmation
- ❌ Appointment rejection and cancellation
- 📊 Administrative reports
- 📈 Appointment history and activity tracking

**Architecture & Technologies**

`C#` `ASP.NET Core MVC` `Entity Framework Core` `SQL Server` `ASP.NET Core Identity` `OAuth` `Windows Forms` `ADO.NET` `JavaScript` `Bootstrap` `SMTP` `Azure`
